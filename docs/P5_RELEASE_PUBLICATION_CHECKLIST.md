`2d2a820`, база `main` @ `511bd8d`). Каждый публичный/необратимый шаг требует
отдельного подтверждения владельца (🔒).

## Контрольные инварианты (проверяются на каждом шаге)

- Подпись Release-артефакта — только оригинальный сертификат `f6a2e4a5…`;
  сборка без keystore блокируется задачей `validateReleaseSigning`
  (подтверждено в P5A).
- `versionCode` монотонно растёт; package ID и данные пользователя не меняются.
- Модели OpenRouter — только `:free`; Railway и ключи не меняются.
- Никаких новых разрешений Android; C15 отсутствует.
- История Git публичного репозитория не переписывается (только fast-forward
  merge подготовленной ветки).
